## 核心思路

同一个主体有三种作用：小捞负责日常经历与使用；深层小捞负责持续保存原始内容；夜班小捞独立整理活跃记忆的目录与事件字典。

原始历史与活跃记忆分开。前者持续追加，后者可以合并、迁移、磨损与退出。找到内容后返回完整文件名，调用者读取整页；页面负责连带，具体事件负责升温和保护。

夜班使用可配置保护期、由多个标签组成的一句话、目标层级准入检查和三次磨损标准。新内容默认保护三天，旧事重现保护减半；容量全受保护时允许临时超容。持续发生的事件可以持续合并和保持保护。

## FAQ 中保留的讨论

为什么整页读取不等于整页升温；为什么升温不恢复细节；持续买早饭为何可以持续受保护；换箱子为何不必磨损；保护期结束为何不必下移；目录太大如何增加上级；为何必须返回完整文件名；原始历史仍在为什么还算遗忘；快照为何不应成为额外记忆库。

FAQ 采用最终确认规则，对旧方案中的“每晚十处”“每天掉一格”等已弃用设定作了说明。
